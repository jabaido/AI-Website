# YinkeidsTech Frontend

Landing page for **YinkeidsTech** — precision wristwatches. Built with Vite + TypeScript.

## Setup

```bash
cd frontend
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start local dev server |
| `npm run build` | Typecheck + production build |
| `npm run preview` | Preview production build |

## Structure

- `index.html` — entry HTML
- `src/main.ts` — page markup + nav / scroll reveal
- `src/style.css` — Apple-inspired responsive styles
- `public/` — static assets (favicon)
